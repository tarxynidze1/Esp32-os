​A high-performance 60 FPS operating system for ESP32-C3 SuperMini. Built for speed, it features a non-blocking architecture, overclocked hardware (160MHz CPU / 400kHz I2C), and seamless multitasking.
​Features
​Gaming: Raycasting DOOM engine, Tetris, Snake, Racer, and Blocks.
​Tools: BLE Mouse (tilt-controlled via ADXL345), scientific calculator, notes, and Wi-Fi NTP clock.
​Optimization: Pure non-blocking code, stable 60 FPS, and hardware-accelerated rendering.
​Wiring (GPIO)
​I2C (OLED/ADXL): SDA=8, SCL=9.
​Buttons: Connect 5 buttons between GND and GPIOs 0, 1, 3, 4, 5 (Internal Pull-ups).
